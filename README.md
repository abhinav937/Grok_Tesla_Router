# Tesla Trip Planner

A Progressive Web App that turns a single natural language sentence into a full road trip, ready to send to your Tesla.

## How it works

1. **Type your trip** — e.g. _"Madison WI to Austin TX, BBQ stop in Kansas City, scenic through Texas Hill Country"_
2. **Watch Grok think** — reasoning streams live in the sidebar as Grok 3 Mini plans your route
3. **Route appears** — Google Maps calculates legs, distances, and drive times; the route animates onto the map
4. **Send to Tesla** — tap "Open in Google Maps" → Share → Tesla app → Send to Car

## Features

- Natural language trip planning powered by xAI Grok 3 Mini
- Live reasoning trace — watch Grok's thinking tokens stream in real-time with token counts and latency
- Interactive dark map with animated route drawing (Tesla red polyline)
- Street View thumbnails for every stop in the sidebar
- Click any map marker for a Street View preview popup
- Satellite / Road map toggle
- Leg-by-leg breakdown — distance, drive time, and route summary per segment
- Trip notes generated by Grok
- "Open in Google Maps" button with pre-built multi-stop URL for Tesla handoff
- Installable PWA — works offline, Add to Home Screen on iOS and Android

## Getting Started

### 1. Clone and install

```bash
git clone https://github.com/abhinav937/Grok_Tesla_Router
cd Grok_Tesla_Router
npm install
```

### 2. Set environment variables

Copy the example and fill in your keys:

```bash
cp .env.example .env.local
```

```env
XAI_API_KEY=xai-...
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=AIza...
GOOGLE_MAPS_SERVER_API_KEY=AIza...
```

### 3. Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## API Keys Setup

### xAI (Grok)

Get your key at [console.x.ai](https://console.x.ai). The app uses `grok-3-mini` by default. Override with `XAI_MODEL=grok-3` in your env for higher quality.

### Google Maps

You need **two separate keys** — one for the browser, one for the server.

Go to [Google Cloud Console](https://console.cloud.google.com) → APIs & Services → Library and enable:

| API | Used for |
|---|---|
| Maps JavaScript API | Map display (browser key) |
| Places API | Address resolution (browser key) |
| Directions API | Route calculation (server key) |
| Street View Static API | Stop thumbnails (server key) |

**Browser key** (`NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`)
- Application restriction: HTTP referrers → your domain + `http://localhost:3000/*`
- API restriction: Maps JavaScript API + Places API only

**Server key** (`GOOGLE_MAPS_SERVER_API_KEY`)
- Application restriction: none (Vercel IPs vary)
- API restriction: Directions API + Street View Static API only

## Deploy to Vercel

```bash
vercel --prod
```

Add the three environment variables in your Vercel project under **Settings → Environment Variables**, then redeploy.

After deploying, add your `*.vercel.app` domain to the browser key's HTTP referrer restrictions in Google Cloud Console.

## API Routes

| Route | Method | Description |
|---|---|---|
| `/api/plan-trip` | POST | Streams Grok reasoning + structured trip plan as NDJSON |
| `/api/directions` | POST | Proxies Google Directions API, returns legs + polyline |
| `/api/streetview` | GET | Proxies Google Street View Static API, returns image |

## Tesla Integration

The app uses the **Google Maps → Tesla app → Send to Car** workflow — no Tesla API credentials needed.

The "Open in Google Maps" button constructs a URL in the format:
```
https://www.google.com/maps/dir/?api=1&origin=...&destination=...&waypoints=stop1|stop2&travelmode=driving
```

In Google Maps on your phone: tap **Share** → select **Tesla** → **Send to Car**.

**Future v2:** Direct Tesla Fleet API integration using `navigation_waypoints_request` to push the full route straight to the car's navigation without the Google Maps step. Requires a Tesla Developer account and virtual key setup.
